# Sistema de Vendas 📊

Sistema web interativo para cadastro, gerenciamento e análise de vendas desenvolvido em Python.

## 🚀 Funcionalidades
- **Formulário de Cadastro:** Registro rápido de novas vendas via barra lateral (sidebar).
- **Base de Dados Persistente:** Armazenamento automático em arquivo CSV.
- **Tabela Interativa:** Visualização completa e dinâmica do histórico de vendas.
- **Dashboard Analítico:** Faturamento total e gráficos interativos (barras empilhadas e pizza) usando Plotly.

## 🛠️ Tecnologias Utilizadas
- **Python**
- **Streamlit** (Interface Web)
- **Pandas** (Manipulação de Dados)
- **Plotly** (Gráficos Interativos)
